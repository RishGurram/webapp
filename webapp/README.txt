Prerequisites for building and deploying my application locally are :
1. Fastapi
2. Virtual Enviroment
3. SQLAlchemy
4. Pydantic
5. psycopg2
6. Bycrypt
7. Json
8. base64
9. passlib
10. Pytest

Build and Deploy instructions for the web application are :
1. Enter the virtual enviroment venv using source venv/bin/activate command.
2. Follow it with source .venv command to connect the database.
3. To start the server use uvicorn main:app command and check the actions executions. 
4. If you want to test the application use pytest command.
